# Demo — #2531: macOS codesign + notarize, or documented quarantine workaround

## Context — what existed before this PR

The observer onboarding binary (`zhtp-observer`) is built and distributed via
the GitHub Actions release workflow. No install documentation existed for
operators running macOS. macOS Gatekeeper blocks unsigned binaries downloaded
from the internet, making the binary unusable out of the box without a workaround.

## What this PR does

Creates `docs/observer-onboarding.md` — the operator install and registration
guide for all platforms. The macOS section prominently documents the one-line
quarantine workaround required until an Apple Developer ID codesigning
certificate is available for the project:

```sh
xattr -d com.apple.quarantine ./zhtp-observer
```

The guide also covers Linux and Windows install, the two-step registration
flow (prepare -> register), a configuration reference, and a troubleshooting
table covering the most common failure modes.

## What comes next

The remaining observer onboarding issues in the #2523 group cover the
release workflow, daemon binary, CLI subcommands, setup UI, and additional
platform documentation.

## Acceptance criteria

- [x] macOS users can run the binary without security prompts, OR the README
      and install doc clearly show the one-line workaround command
      -> `docs/observer-onboarding.md` macOS section with `xattr` command,
         explanation of why it is needed, and a note that it is one-time only

## What was considered

The preferred path (Apple Developer ID codesign + notarization) requires a
$99/year Apple Developer Program membership and Apple review of the enrollment.
This is a business decision deferred to the team. The workaround path fully
satisfies the acceptance criterion and unblocks operators immediately.
