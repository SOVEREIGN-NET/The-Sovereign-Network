Mission Profile

Restore an existing identity or commission a new node persona, then stay on top of height, wallet state, validator presence, and registration status without leaving localhost.

Recovery Input
Seed Phrase

Paste the full phrase into any field or enter words one by one. Tab keeps natural browser navigation, and arrow keys or Enter advance through the grid. Accepts 20-word (legacy) or 24-word (BIP39) phrases — leave the remaining cells empty for a 20-word phrase.

Operational Notes
Seed Hygiene

The recovery phrase is never logged and is only sent once to `POST /api/setup` when you explicitly restore.

Local Bridge

This interface runs from the CLI binary at `localhost:7840`, while node state is proxied over QUIC.

Live Polling

Dashboard telemetry refreshes every 2.5 seconds and can be forced manually at any time.
